# About this repo
This is a repository for showcasing an end-to-end bank customer churn prediction pipeline.

# Geting Started
## Prerequisites
- Python >= 3.10, <3.13
- Docker
- Pixi (optional)

## Installation
Multiple package manager can be used to install the dependencies (from `pyproject.toml`) but pixi is used for this demo.
```bash
# pixi (Recommended)
pixi install

# pip
pip install -e .

# uv
uv pip install
```

1. Download the dataset
```bash
make data
```
